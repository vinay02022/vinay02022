## About

I'm a **Full-Stack Engineer** focused on **AI-native systems** — production-grade backends, multi-tenant LLM infrastructure, and data-heavy pipelines. I build the full stack: FastAPI / NestJS services wired to Next.js frontends, connected through real AI reasoning layers, not just LLM wrappers.

- **Currently shipping** AI trading systems, multi-tenant LLM gateways, and decision-debugging tools
- **Stack of choice** Next.js · TypeScript · Python · FastAPI · NestJS · PostgreSQL · Redis
- **AI layer** Gemini · OpenAI · Anthropic · RAG · knowledge graphs · agentic pipelines
- **Writing** technical deep-dives on [Medium](https://medium.com/@techievinay01)
- **Open to** senior full-stack / AI engineer roles and technical co-founder conversations
